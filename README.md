# Consumer Behavior Analysis using Python

## 📊 Project Overview

This project analyzes Diwali sales data to understand customer purchasing patterns and generate meaningful business insights.

The analysis was performed using Python and focuses on customer demographics, purchasing behavior, product demand, and sales performance.

## 🎯 Objective

The main objective of this project is to use exploratory data analysis techniques to understand consumer behavior and transform raw sales data into useful business insights.

## 🛠️ Tools & Technologies

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Jupyter Notebook

| **Library**          | **Where I used**                                                                                                                                                           |
| -------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Pandas**           | Loading the CSV with `pd.read_csv()`, checking missing values with `pd.isnull()`, and throughout the analysis using `groupby()`, `sum()`, `sort_values()`, `head()`, etc.           |
| **NumPy**            | Imported as `np` in **Cell 1**.                                                                                            |
| **Matplotlib**       | Imported as `plt` in **Cell 1**. Used in the additional analyses with `plt.title()`, `plt.xlabel()`, `plt.ylabel()`, `plt.show()`, `plt.subplots()`, and `plot(kind='bar')`.        |
| **Seaborn**          | Used extensively for visualizations with `sns.countplot()` and `sns.barplot()` across gender, age group, state, marital status, occupation, product category, and product analyses. |
| **Jupyter Notebook** | Used as the environment where the Python analysis, visualizations, and project documentation were performed.                                                                        |


## 🔍 Analysis Performed

The project includes:

* Data cleaning and preprocessing
* Customer purchasing pattern analysis
* Sales analysis by gender and age group
* Sales analysis by state and occupation
* Product category analysis
* Average Order Value by Age Group
* Top 10 Products by Orders
* Revenue per Order by State
* Data visualization and Exploratory Data Analysis (EDA)

## 📈 Key Insights

The analysis helps identify:

* Differences in average order value across age groups
* Products with the highest number of orders
* States generating relatively higher revenue per order
* Customer purchasing patterns across different demographic groups
* Product demand across different categories

## 📌 Conclusion

The Diwali Sales Analysis helped identify important patterns in customer purchasing behavior and sales performance.

- Average Order Value varies across different age groups.
- The Top 10 Products by Orders highlight products with higher customer demand.
- Revenue per Order by State helps identify states generating relatively higher revenue per order.
- The analysis also explores purchasing patterns across gender, age group, state, occupation, and product category.
- These insights can help businesses better understand their customers, identify high-demand products, and make more informed marketing and sales decisions.

Overall, this project demonstrates how Python can be used to clean, analyze, visualize, and extract meaningful business insights from sales data.
